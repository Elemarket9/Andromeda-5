# Contributing and independent scientific review

We welcome independent critique, replication, corrections and stronger falsification tests.

Distinguish explicitly among: (1) mathematical derivation, (2) numerical simulation, (3) secondary data analysis, and (4) independent laboratory measurement.

For an issue or contribution, state: exact claim, governing equations, units, parameter choices, references, code and numerical tolerances, and a falsifiable prediction. Do not claim physical discoveries from software-only tests.

For Phase 9, first check the torque transcription against the original dissertation. A valid two-pole exclusion requires instrument-specific responses and their joint uncertainties, not just published marginal single-Yukawa fits.

No faster-than-light signal or novel force has been detected by this project.
