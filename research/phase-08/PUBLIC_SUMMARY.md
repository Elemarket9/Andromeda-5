# ANDROMEDA-5 Phase 8 — Research Invitation

We have developed a falsifiable *cross-observable test* for a hypothetical matter-coupled scalar field with modified dispersion. The same two parameters would govern both a predicted short-range additional force and the field's predicted frequency-dependent group velocity. We derived identities linking those observables, independently checked selected Fourier integrals numerically, and released source code and tables.

**What we did not find:** We did not measure a new force, observe a new particle, demonstrate faster-than-light information transfer, or disprove relativity. The higher-derivative framework has significant scientific prior art; independent novelty assessment is required.

We invite experts in precision force experiments, Lorentz-violation tests and quantum field theory to audit the derivations and identify decisive existing constraints. We particularly seek access to instrument-level torque data and likelihood information for the relevant short-range gravity experiments.

All sample parameters are illustrative, all numerical tests are simulations or mathematical checks, and the scientific hypothesis should be rejected if it contradicts reproducible measurements.
