# Phase 10 — Experimental-model reconstruction and independent review

**Status: unreviewed mathematics and synthetic tests, not a discovery.**

Phase 10 tests whether a hypothetical two-component short-range potential can be turned into a reproducible torque-level prediction. We explicitly do **not** claim a fifth-force detection, faster-than-light transmission, or a statistically justified exclusion using the real 2020 Eöt-Wash measurements.

Run `python phase10_minimal_repro.py` with Python 3, NumPy and SciPy. Full Phase 10 source and synthetic outputs are also available in the complete research pack linked from the project discussion.

**Important:** The synthetic point-ring geometry used to test numerical methods is **not** the physical Lee et al. (2020) torsion-balance apparatus. The exact experimental two-pole likelihood remains to be reconstructed.
